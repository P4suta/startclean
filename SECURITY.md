# Security policy

Please report potential unsafe deletion, path-containment, elevation, or Shell
Link parsing issues privately through GitHub's security advisory interface.
Do not include sensitive local paths in a public issue.

Only the latest release receives security fixes. Released binaries are unsigned
until the project has a code-signing certificate. Verify the published SHA-256
checksums and the Sigstore-backed GitHub artifact attestation before execution:

```powershell
gh attestation verify .\startclean_*_Windows_x86_64.zip --repo P4suta/startclean
```

Each release also includes SPDX 2.3 and CycloneDX JSON SBOMs generated by Syft.
An attestation proves build provenance, not that an artifact is vulnerability
free; consult the SBOMs and published security advisories as well.

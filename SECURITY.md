# Security policy

Please report potential unsafe deletion, path-containment, elevation, or Shell
Link parsing issues privately through GitHub's security advisory interface.
Do not include sensitive local paths in a public issue.

Only the latest release receives security fixes. Released binaries are unsigned
until the project has a code-signing certificate; verify the published SHA-256
checksums and GitHub artifact attestations.
